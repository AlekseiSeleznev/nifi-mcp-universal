# Проверка обновления от 4 октября 2026 года

## Задание

Сверить проект с принятым upstream, полностью проверить код, исправить
подтверждённые ошибки, развернуть проверенную сборку локально и на сервере
LUVE, повторить проверки после развёртывания, затем слить в `main` и отправить
в GitHub. Проверить Windows-установку и чистоту рабочих каталогов.

База проверки: `bddc24dc6fbfc1d4690d11d054207e6421f4de07`.
Источник и его актуальная ревизия: [upstream.md](upstream.md).

## Подтверждённые исправления

- Windows installer проверяет коды возврата Docker Compose, Codex и настройки
  автозапуска; ошибка готовности завершает установку с ошибкой.
- PowerShell smoke checks прекращаются при ошибке внешней команды.
- Windows Compose использует стандартную сеть при сборке образа.
- `test_nifi_connection` проверяет сохранённые подключения по имени, включая
  сертификаты; временная HTTP-сессия закрывается и при ошибке проверки.
- Происхождение заимствованных модулей и лицензия входят в репозиторий и образ.

## Проверки

Первоначальный полный прогон: 575 тестов, 100% покрытия строк и ветвлений.
Ошибки установщика и проверки соединения воспроизведены регрессионными тестами
до исправления. Итоговые результаты CI, развёртывания и повторных проверок
добавляются после их завершения.

Проверки реальных NiFi выполняются чтением через MCP. Изменение потоков,
запуск процессоров и очистка очередей в эту работу не входят.
Настоящий Docker Desktop на Windows требует отдельного доступного Windows
хоста; границы CI-проверки описаны в [upstream.md](upstream.md).
